# Metrics

## North Star Metric
**Audits Completed** — Measures core value delivery. More audits = more leads for Credex.

## 3 Input Metrics
1. **Audit completion rate** — % of visitors who finish form and run audit
2. **Email capture rate** — % of audit viewers who submit email
3. **Share rate** — % of users who copy/share audit URL

## What to Instrument First
- Funnel tracking: Page view → Add tool → Run audit → View results → Submit email
- Tool popularity: Which tools are most commonly audited
- Savings distribution: Average savings per audit

## Pivot Trigger
If email capture rate < 15% after 100 audits, pivot to:
- Show email gate BEFORE results
- Add "email me this audit" as primary CTA
